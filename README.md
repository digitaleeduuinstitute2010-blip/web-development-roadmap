# 🗺️ Web Development Roadmap for Beginners

A step-by-step path for students starting web development from zero.

## Step 1: HTML (1–2 weeks)
- [ ] Headings, paragraphs, links, images
- [ ] Lists, tables, forms
- [ ] Semantic tags (header, nav, main, footer)

## Step 2: CSS (2–3 weeks)
- [ ] Selectors, colors, fonts
- [ ] Box model, flexbox, grid
- [ ] Responsive design with media queries

## Step 3: JavaScript (4–6 weeks)
- [ ] Variables, functions, loops
- [ ] DOM manipulation and events
- [ ] Fetching data from APIs

## Step 4: Git and GitHub
- [ ] `git init`, `add`, `commit`, `push`
- [ ] Branches and pull requests

## Step 5: WordPress (optional path)
- [ ] Themes and plugins
- [ ] Building a business website
- [ ] WooCommerce basics

## Step 6: React
- [ ] Components and props
- [ ] State and hooks
- [ ] Build a small project

## 🛠️ Practice projects
1. Personal portfolio page
2. Restaurant landing page
3. To-do list app
4. Weather app using an API
5. Simple online store (WooCommerce)

## 📖 Tips
- Build something after every topic.
- Commit your code daily.
- Read other people's code.
